⚙ Higher-Order Functions

A Higher-Order Function (HOF) is a function that takes a function as an argument, or returns a function, or both. Possible only because in JavaScript functions are first-class citizens — values you can store, pass, and return like numbers.

1Functions are values — the superpower behind everything

You can put a function in a variable, pass it to another function, and return it from one. If you've done the closures tab, you've already SEEN this: createCounter returned a function — so it was a HOF all along! 

const greet = function () { return "hello"; };  // stored in a variable
function callTwice(fn) { fn(); fn(); }              // passed as an argument → HOF
function makeCounter() { return function () {...}; } // returned → HOF (+ closure!)
→ click to see a function travel as a value

2The Namaste JS classic — extract WHAT varies, share what doesn't

Bad code: calculateArea(radius), calculateCircumference(radius)… each repeats the same loop (violates DRY — Don't Repeat Yourself). Insight: the loop is the same, only the math differs. So pass the math in as a function! 

const radius = [1, 2, 3, 4];

const area          = r => Math.PI * r * r;   // just the logic, no loop
const circumference = r => 2 * Math.PI * r;
const diameter      = r => 2 * r;

function calculate(arr, logic) {        // ← HOF: the reusable loop
  const output = [];
  for (const r of arr) output.push(logic(r));
  return output;
}
calculate(radius, area);   // same loop, ANY logic 🎯
1234→ pick a logic…
This IS map: our calculate(arr, logic) is a homemade arr.map(logic). You just wrote a polyfill of map without noticing.

3The big three HOFs: map · filter · reduce

All three take your function and apply it across an array — but each answers a different question: map = "transform each" · filter = "keep which?" · reduce = "boil down to one value". Watch each element flow through: 

const nums = [1, 2, 3, 4, 5, 6];
nums.map(n => n * 2);              // [2,4,6,8,10,12] — same length, transformed
nums.filter(n => n % 2 === 0);    // [2,4,6] — only the ones that pass the test
nums.reduce((acc, n) => acc + n, 0); // 21 — one single value
→ pick one…
→ the log shows YOUR function being called once per element

4Full circle: debounce is a HOF + closure

Now you can name what debounce really is: a higher-order function (takes fn, returns a new function) whose returned function uses a closure (remembers timerId) and the event loop (setTimeout / clearTimeout). Three concepts, one tool: 

function debounce(fn, delay) {   // HOF: function in…
  let timerId = null;            // closure: remembered between calls
  return function (...args) {    // …function out
    clearTimeout(timerId);       // event loop: cancel browser timer
    timerId = setTimeout(() => fn(...args), delay);
  };
}

Other everyday HOFs you now recognize: addEventListener(type, fn), setTimeout(fn, ms), arr.sort(compareFn), promise.then(fn) — you've been using HOFs since your first line of JS.

Interview one-liner: "A higher-order function takes and/or returns functions. map/filter/reduce take one; debounce and createCounter return one. It works because functions are first-class values in JavaScript."
