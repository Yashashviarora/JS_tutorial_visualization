🍛 Function Currying

Currying turns f(a, b, c) into f(a)(b)(c) — a chain of one-argument functions. Each call collects one argument into a closure 🎒 and returns a function waiting for the next. Closures as an argument-collecting machine.

1sum(1)(2)(3) — watch the backpacks stack up

function sum(a) {
  return function (b) {
    return function (c) {
      return a + b + c;   // a and b arrive via the closures 🎒
    };
  };
}

Click the buttons in order. Notice: the first two calls compute NOTHING — they only collect.

→ click sum(1)…
→ each step returns a new function carrying a bigger backpack

2The real power: stop halfway and reuse

Fill in only the first argument, save the half-done function, reuse it forever. This is partial application — building specialized functions from a general one: 

const multiply = (a) => (b) => a * b;

const double = multiply(2);   // a=2 locked in the backpack
const triple = multiply(3);   // separate backpack with a=3
→ two saved functions, two independent backpacks (sound familiar? counterA / counterB!)
Also possible with bind (tab 7!): const double = multiply.bind(null, 2) — bind can pre-fill arguments, not just lock this. Two roads, same destination: a function with values baked into its backpack.

3Interview classic: infinite currying — sum(1)(2)(3)…()

function sum(a) {
  return function (b) {
    if (b === undefined) return a;  // empty call () → stop, return the total
    return sum(a + b);              // else → fold it in, return a new collector
  };
}
sum(1)(2)(3)(4)();   // 10

Keep adding numbers; the running total lives in the closure. The empty call is the stop signal:

→ running total appears here
→ every click returns a NEW collector closing over the new total

4Say it in one breath

Currying = converting f(a,b,c) into f(a)(b)(c), where each call captures one argument in a closure and returns the next function. Why: partial application — preset some arguments once (config, tokens, log levels) and reuse the specialized function everywhere. How: nested closures, or bind with preset args. It's closures (tab 1) + HOFs (tab 6) + bind's trick (tab 7) rolled into one pattern.
